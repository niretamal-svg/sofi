# SOFI Starter — Primera Entrega

Starter inicial alineado con la documentación del proyecto:
- `api/` → Node.js + Express + MongoDB
- `web/` → React + Vite
- `infra/` → Docker + GitHub Actions

## Qué incluye
- Login base con JWT
- Health check
- Estructura en capas
- Modelo `User`
- Conexión MongoDB
- Docker Compose con API, Web, Mongo y Redis
- Guía paso a paso
